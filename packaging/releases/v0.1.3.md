A fix for Windows Defender flagging the launcher.

Windows Defender's machine-learning heuristics flagged the 0.1.2 launcher as `Trojan:Win32/Bearfoos.A!ml`. It was a
false positive: the new pack store sign-in kept its token in a file the launcher decrypted at every start, and opened
your browser through `rundll32`, both of which look like what password-stealing malware does.

## What changed

- **Your pack store sign-in is kept in Windows Credential Manager**, as Git, the GitHub CLI and VS Code keep
  theirs. If you signed in with 0.1.2, log in once more.
- **Links open in your browser the standard way** (ShellExecute).

If Windows Security quarantined the 0.1.2 launcher, install this version over it. The launcher is our own build from
the source in this repository; the release's `SHA256SUMS` lists every file's checksum.

> [!NOTE]
> This is still a very early, work-in-progress build.

## Installing

- **Windows:** run `QWCRemastered-0.1.3-setup.exe`.
- **Linux:** run the AppImage, or unpack the tarball and run `qwc-launcher`.

Your library (the imported game, your packs and settings) stays in your user profile when you update or uninstall.
